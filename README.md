# EVERTRACE

> **"Every memory leaves a trace."**  
> *AI-powered personal memory and audiovisual heritage archive for Hacktoberfest Hack Day 2026 — Track 2: Best Open-Source AI Project (Audiovisual Heritage Day).*

The complete project is located in [`evertrace/`](./evertrace).

## Quick Start from Workspace Root:

1. **Start the application:**
   ```bash
   npm start
   ```
   *Opens server at `http://127.0.0.1:3000`*

2. **Run the test suite:**
   ```bash
   npm test
   ```
   *Runs 20 automated unit and integration tests across schemas, security, and AI relay.*

For the complete architectural overview, visual design documentation, and API reference, see [evertrace/README.md](./evertrace/README.md).
